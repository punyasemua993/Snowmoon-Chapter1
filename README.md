# Snowmoon — Chapter 1 AI Anime Pipeline

Reproducible production materials for a short AI-anime adaptation of Snowmoon Chapter 1.

## Source
- https://vitalik.eth.limo/snowmoon/
- https://vitalik.eth.limo/snowmoon/html/chapter-1.html

The Snowmoon site states that the work is GPL v3 and explicitly says that if it is turned into a movie or AI anime, the pipeline (AI prompts, scripts, task-specific harness, etc.) and other non-commodity materials used should be open-sourced.

## Contents
- `01-source/` — supplied Chapter 1 reference PDF and source notes
- `02-screenplay/` — shot manifest + dubbing script
- `03-prompts/` — global, character, environment, negative and shot prompt system
- `04-production-workflow/` — reproducible generation/edit/QC workflow
- `05-voices/` — Japanese voice-performance profiles and provenance requirements
- `06-assets/` — asset inventory/placeholders
- `07-legal/` — attribution and license notes
- `08-manifests/` — generation log, provider notices, SHA-256 manifest

## Reproducibility
Record actual provider/model/version, seed, settings, reference IDs, voice model/version and generation date for every generated asset. Do not commit API keys or private credentials.
